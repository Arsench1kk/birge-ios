После индексации и взвешенной суммы число переменных не уменьшилось (домен сохранён), время создания переменных — 10,679 с, установки цели — 9,095 с; 126 дополнительных ограничений задают симметрию. Полное время с cProfile 45,247 → 41,744 с. Для 240 заявок отдельное измерение стало дольше: 1,904 → 1,956 с. Нельзя считать эти единичные замеры доказательством стабильного ускорения.

Индексирование окон устраняет повторную фильтрацию для каждого водителя; пустые кандидаты и дубликаты минут исключены. Ограничения симметрии сохраняют оптимум только для полностью взаимозаменяемых водителей, обоснование — `docs/ilp_formulation.md`. Сетка не урезана произвольным лимитом, поскольку это может изменить оптимум. Построение порядка 42 с при 5000 заявках остаётся риском; следует измерять его отдельно от времени поиска.
