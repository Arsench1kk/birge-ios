Control получил 0 глобальных OPTIMAL из 20 для обоих режимов; чистая декомпозиция хуже baseline в 17/20 пар (stage3/report.md). Значительное число бинарных переменных и оставшиеся gap при лимите показывают, что доказательство оптимума не достигнуто, но эти измерения сами по себе не устанавливают единственную причину. Симметрия и построение сетки влияют на размер/поиск; causal-абляции здесь нет.

Для новой версии реализовано дополнительное безопасное сокращение: если водитель на дату индивидуально совместим ровно с одной заявкой, доминируемые минуты для неё удаляются (минута hint сохраняется). Симметрия и фильтр пустых рейсов уже были реализованы; тесты сравнивают цель с замороженной моделью до сокращений на 20 малых случаях и эталонах. Применимость нового правила к записанным моделям и ускорение для control без повторного построения **не измерялись**.
